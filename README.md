# Secretaria Online — Portal do Funcionário

Protótipo **100% front-end**, sem backend, desenvolvido para demonstração da visão da Secretaria Online institucional da Universidade Rovuma.

## Estrutura

- `index.html` — interface principal
- `assets/styles.css` — design responsivo
- `assets/app.js` — navegação e interacções simuladas

## Como executar

Pode abrir `index.html` directamente no navegador ou publicar a pasta num serviço de hosting estático.

## O que está demonstrado

- Dashboard do funcionário
- Catálogo de serviços administrativos
- Nova solicitação com formulário e anexos
- Número de processo
- Minhas solicitações
- Estados e acompanhamento por etapas
- Perfil do funcionário
- Configurações
- Modal de detalhe do processo
- Layout responsivo para computador e telemóvel

## Próxima fase

O protótipo está preparado para, numa fase posterior, ligar a:
- autenticação institucional;
- base de dados;
- motor de workflow;
- permissões por Unidade Orgânica;
- notificações;
- arquivo documental;
- assinatura/despacho digital;
- auditoria e histórico de tramitação.

> Os dados apresentados são fictícios e servem apenas para demonstração.
