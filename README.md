# Secretaria Online — Protótipo simples

Protótipo **100% front-end**, sem backend, para demonstração da tramitação administrativa da Universidade Rovuma.

## Objectivo desta versão

A interface foi simplificada para concentrar-se nas operações essenciais:

- criar uma solicitação;
- receber e verificar;
- devolver ou encaminhar;
- solicitar parecer;
- acompanhar a tramitação;
- tomar decisão;
- consultar o processo.

## Perfis simulados

- Estudante — Nível I
- Secretaria — Nível I
- Gabinete do Reitor
- Director da FACEE — Nível II
- Director Adjunto Pedagógico — Nível II
- Chefe de Departamento — Nível II
- Director do Curso — Nível II
- Reitor — Nível III

Use **Simular utilizador** no topo para percorrer o sistema.

## Fluxo demonstrativo

Estudante → Secretaria → Gabinete do Reitor → Unidade Orgânica → cadeia hierárquica de parecer → Gabinete → Reitor → decisão.

O protótipo demonstra também que o Gabinete pode solicitar parecer a uma ou várias Unidades Orgânicas.

Todos os dados são fictícios.
